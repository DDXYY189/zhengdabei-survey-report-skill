# zhengdabei-survey-report-skill

正大杯全国大学生市场调查与分析大赛报告研究 Skill。它以真实问题、可追溯调查和问题导向的方法选择为主线，支持从研究设计到报告审计；不默认包含 PPT 和答辩。

主 Skill：`skills/zhengdabei-survey-report/SKILL.md`

参考文件：

- `references/method-routing.md`：按研究目标和数据形态选择方法；
- `references/quality-gates.md`：调查、数据、模型和提交审计；
- `references/report-templates.md`：Intake、方案、变量、结果和建议模板；
- `tests/pressure-scenarios.md`：验证 Skill 不跳过证据门槛、不编造结果。
