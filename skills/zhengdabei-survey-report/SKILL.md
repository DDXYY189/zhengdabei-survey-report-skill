# 正大杯市场调查与分析大赛报告写作

本 skill 帮助团队在**已确定选题**的前提下，完成正大杯全国大学生市场调查与分析大赛的参赛报告，覆盖从研究设计到成文的全流程。**不含 PPT 制作与答辩环节**。本 skill 经研读 10+ 篇国赛获奖/优秀报告归纳而成，遵循获奖作品的共性规律。

## 核心定位与前提

- **必要条件**：队伍必须提供选题。本 skill 不负责选题开发；若用户尚未提供选题，先提示暂不可启动，并列出选题所需信息（研究对象、现象、可获取数据类型）。
- **输出物**：按正大杯格式要求排版、正文约两万字级、总决赛全文约 50~65 页（以当年赛区通知为准）的参赛报告。
- **评审导向**：评委按七维度打分——**研究选题、文献与文案研究、方案设计、调查实施、分析与结论、报告文本、研究创新**。全部写作围绕拿高分展开。

## 国赛获奖报告的共通规律（研读 10+ 篇的提炼）

1. **"问题提出—调查设计—数据质量—描述分析—模型实证—结论建议—完整附录"是标准骨架**。每篇必含：封面、摘要、关键词(3-5个)、目录、绪论(背景/问题/意义/文献/技术路线)、调查方案设计、信效度检验、描述性分析、模型分析、结论与建议、参考文献、附录。
2. **必须有"研究技术路线图/研究框架图"**，放在绪论，让评委一眼看懂"问题→数据→模型→结论→建议"逻辑链。
3. **模型必须对应明确研究问题**，不是炫技。每个模型都要回答一个问题：Logit→哪些因素影响选择；聚类→人群如何细分；IPA→哪些指标要优先改进；SEM→潜变量间的作用路径；文本挖掘→用户真实关注点。
4. **多源数据三角互证**：问卷 + 深度访谈 + 二手/宏观数据 + 评论文本/开放题，形成证据链，增强结论可信度。
5. **信效度必报**：Cronbach α、KMO、Bartlett，使用 SEM/PLS-PM 的报告必须报告模型拟合指标（CFI、TLI、RMSEA、SRMR、χ²/df）。
6. **完整附录是规范性加分项**：调查问卷、访谈提纲、抽样表、变量编码表、信效度表、模型代码、调查过程记录。
7. **建议分层、具体**：按政府/企业/平台/高校/消费者等主体拆分，每条建议对应前文结论，杜绝"加强宣传、提高质量"式空话。
8. **标题有小节有表达力**："读研热的冷思考""让中药飞""摩拜能否真的'摩拜'"式标题，主副题结构——主标题抓眼球（"滴水思情，奈何'愁'"），副标题点明对象/方法/切口，吸引评审。
9. **用户画像可独立成章**：聚类/细分不只做附表，而是形成"人群类型 + 行为特征 + 营销对策"的独立章节（如跑者分赛事党/进取党/娱乐党/酱油党，轻食分潜在/主力/保守/跟风人群）。
10. **文本挖掘贯穿前后**：抓取的评论/开放题既用于问卷前修正设计，也用于结论后解释洞察，形成"线上大数据发现痛点→线下问卷实证用户"的双证据链。（电商平台评论、携程/马蜂窝/美团评论、百度贴吧等）
11. **模型结果转化为可执行动作**：RFM 找主力客户、KANO 定功能优先级、决策树找推广人群、LDA 提取宣传关键词、联合分析直接对应产品属性设计——每个模型结论都要落到下一步怎么做。
12. **建议遵循"问题—证据—策略—落地动作"**：分主体（政府/企业/平台/高校/消费者等）后，再给具体动作（如"订餐每餐50元""标注卡路里""共享单车免费体验5次"），杜绝空话。
13. **B端/产业类选题加分**：校企平台、地方银行转型、制造业升级等产业/行业调查，加入经营数据、效率模型（如 DEA）、SWOT/PEST，比纯消费者调查更显专业。

## 团队角色（四人分工）

四人角色在用户原始分工基础上，经国赛论文研读细化而成：

### 成员一：编程与数据求解（推荐计算机类 > 统计学 > 理工科其他）
1. **数据采集与文本**：必要时用 Python 爬虫；题目适合文本分析时用去重/分词/词频/情感/LDA主题模型/词云。**非所有主题都适合文本分析**，先判断。
2. **数据可视化**：matplotlib/seaborn/plotly/pyecharts 绘制高级数据图用于描述性分析。
3. **统计建模求解**：推荐 Stata 与 SPSS（Amos 做结构方程）；复杂方法（随机森林、PLS-PM、LDA 等）用 Python/R。B 站有 Stata 详细视频。
4. **算法复盘**：总结国赛报告中别人如何套用模型、用什么软件求解，再去学对应软件操作。
5. **黑匣子模型差异化**：随机森林、神经网络等 ML 在统计建模中少用但能突出区分度，可谨慎引入并说明可解释性。

### 成员二：建模与模型套用（推荐统计学 > 数学 > 其他理工科）
1. **模型归纳**：总结国赛报告的模型——自变量/因变量/指标如何确定、每个模型适合什么问题、检验方法。会套用即可，不必掌握每个公式推导。
2. **资料查询**：借统计建模书籍，遇不会的模型查对应实际案例。
3. **与编程成员紧密协作**：建模与编程分工不过死。
4. **模型-问卷数据匹配**：**多选题难代入模型，量表题（Likert 5/7级）才好代入**；设计问卷时为每个潜变量预留 3~5 个量表题项。

### 成员三：排版与美工（推荐设计类 > 经管类）
1. 负责封面海报、图表、流程图；答辩视频剪辑可交设计类成员。
2. **以模仿为核**：选定一两篇排版美工优秀的国赛报告逐页学习。
3. 表格用三线表或贴合主题的彩色表；研究框架图、路径图、词云、IPA 象限图都要画得专业。
4. **工具**：图怪兽、可画(Canva)做封面/流程图；在线词云；Python 高级图。

### 成员四：文稿与语病修改（推荐文科类）
1. 优秀报告正文约两万字级（国赛），部分赛区限两万字内，撰写前确认所在赛区。
2. 每个成员负责 1~2 个章节（约 15~30 页），成员四负责逐字逐句修改、统一行文风格、理顺逻辑、修正语病——直接影响"报告文本"评分。

## 标准章节结构模板（研读多篇获奖报告归纳）

章节命名与顺序建议：

```
封面（主标题抓眼球 + 副标题说明对象/城市/方法）
摘要（背景1段 + 样本与方法1段 + 核心结论3-5条 + 建议方向）
关键词（3-5个：主题词+对象词+方法词）
目录 / 表格与插图清单

第一章 绪论 / 问题提出
  1.1 研究背景（政策/行业/现实痛点）
  1.2 研究问题与研究目的
  1.3 研究意义（理论+实践）
  1.4 文献综述与理论基础（TAM/UTAUT/感知价值/扎根理论/计划行为等）
  1.5 研究思路与技术路线图（必配框架图）

第二章 调查方案设计
  调查目的 / 调查对象 / 调查方式 / 抽样设计 / 样本量确定
  问卷设计（量表题为主，预留潜变量题项）/ 访谈设计 / 数据收集流程与质量控制

第三章 数据质量检验
  样本回收情况（发放/回收/有效回收率）
  信度检验（Cronbach α）
  效度检验（内容效度/结构效度/KMO/Bartlett，必要时因子分析、CR/AVE）

第四章 描述性分析
  样本特征 / 行为特征 / 态度特征 / 消费特征 / 交叉分析（配高级数据图）

第五章 模型实证分析（按建模方案）
  模型1（如SEM/Logit/聚类/IPA/LDA...）→ 结果 → 解释
  必要时模型2做交叉验证

第六章 原因机制分析（可选，高分项）
  路径图/鱼骨图/SWOT/IPA矩阵，解释"为什么会这样"

第七章 结论与建议
  结论（逐条对应研究问题）
  建议（按政府/企业/平台/高校/消费者等主体拆分，每条对应结论）

第八章 不足与展望
参考文献
附录（问卷/访谈提纲/抽样表/变量编码表/信效度表/模型代码/调查记录）
```

## 统计建模方法库（模型→问题→数据形态 映射）

根据国赛论文，High-Value 常用方法如下。模型选择必须对应研究问题，并满足数据形态要求。

| 方法 | 解决的问题 | 适用的数据形态 |
|---|---|---|
| 描述性统计+交叉分析 | 刻画样本结构、特征、分布 | 单选/多选/排序/量表题 |
| 信效度检验 | 证明问卷质量 | 量表题（Cronbach α、KMO、Bartlett） |
| 因子/主成分分析 | 降维、提炼潜变量 | 多个相关量表题 |
| 多元线性回归 | 连续因变量的影响因素 | 连续/分类自变量 |
| 二元/有序 Logit | 因变量为二分类或有序等级（买不买/等级意愿） | 因变量分类 + 各类前因题项 |
| 结构方程 SEM | 潜变量间作用路径、机制 | 各潜变量 3~5 个量表题，样本≥200 |
| PLS-PM | 复杂模型、样本受限/分布非正态 | 同 SEM，更适合小样本 |
| 聚类分析 | 人群细分/用户画像 | 偏好/感知/频率等多维度题项 |
| IPA 分析 | 重要性-表现矩阵、改进优先级 | 同一指标的重要性与满意度打分 |
| 模糊综合评价 | 难以精确量化的满意度/质量 | 指标体系 + 权重 + 评语集 |
| 层次分析 AHP | 确定指标权重 | 专家/受访者两两比较 |
| 灰色关联分析 | 小样本下因素关联强度排序 | 影响序列与总体序列 |
| 决策树 | 差异分群、最有预测力的变量 | 分类目标 + 多自变量 |
| 关联规则 | 发现因素组合共现 | 二值/分类/多选题 |
| 随机森林 | 指标重要度排序、避免共线性 | 结构化多自变量 |
| LDA 主题模型+情感分析 | 评论文本主题、情感倾向 | 非结构化文本（分词/去停用词/词项矩阵） |
| 词云 | 开放题/评论高频词 | 文本数据 |
| Logistic/SEM 组合 | 因素筛选 + 机制验证 | 量表 + 分类变量 |
| SWOT / PEST | 战略/态势分析 | 调研与访谈结论、环境资料 |
| 联合分析 (Conjoint) | 量化产品属性偏好、识别最重要属性 | 属性的虚拟组合 + 偏好打分 |
| KANO 模型 | 区分基本型/期望型/兴奋型需求 | 对每个功能的正向/负向两个尺度题项 |
| NPS 净推荐值 | 衡量口碑与忠诚度 = 推荐者%-贬损者% | "是否愿意推荐"的 0-10 打分 |
| RFM 分析 | 识别主力/活跃/流失客户价值 | 交易频率/金额/近度数据 |
| 消费强度公式(加权) | 合成多指标为单一强度得分 | 多个消费/态度量表题加权 |
| 二维需求缺陷模型 | 被侵权程度 × 维权难度排序行业优先级 | 两类评判题项各得分，构成矩阵 |
| 综合评价法(客观赋权) | 多维度综合评分（如德智体美劳） | 多维度指标体系 + 权重 |
| BP 神经网络 | 精准推荐/分类匹配（老年人→活动） | 结构化特征 + 分类标签 |
| 贝叶斯决策树 | 内容特征对行为/信任的影响 | 文本/图片特征 + 行为因变量 |
| Heckman 两步回归 | 处理样本自选择偏误的影响因素 | 因变量 + 修正项结构 |
| DEA 效率分析 | 投入产出效率评价（银行/企业） | 企业的投入/产出指标 |
| 对应分析 | 两类分类变量的关联可视化 | 列联表 |
| 差异检验(卡方/Kruskal-Wallis/Fisher) | 组间/多组差异显著性 | 分类自变量 + 连续/等级因变量 |
| 词共现/语义网络 | 文本中关键词关联结构 | 分词后的词频共现矩阵 |

**推荐组合（由简到难）**：
- 基础版：信效度 + 描述统计 + 交叉分析 + 差异检验 + Logit
- 进阶版：Logit + 聚类/IPA + 文本挖掘 + 词云
- 高分版：理论模型 + 信效度 + 因子/主成分 + Logit/SEM/PLS-PM + 文本挖掘(LDA) + 三角互证 + 差异化模型(KANO/NPS/联合分析/RF/DEA 择一切入)
- **B端/产业版**：SWOT + PEST + 财务状况/效率分析(DEA) + 差异化模型

## 报告结构与写作流程（九步）

### 第一步：方案规划（选题到位后）
- 明确研究问题、研究目的与对象；界定四角色章节范围与时间节点。
- 初步确定报告大框架（遵循"一类样本数据单独成章"原则——问卷、访谈、评论文本各单独成章）。

### 第二步：文献与文案研究
- 检索文献，梳理国内外现状，选定理论框架（TAM、UTAUT、感知价值、扎根理论、计划行为、S-O-R、ISM 等）。
- 明确创新点；规划多数据源（问卷/访谈/评论文本/二手数据），为三角互证做准备。
- **文本先行**：若选题涉及评论/开放数据（电商、携程/马蜂窝、贴吧等），可先爬取做词频/LDA/情感分析，其发现用于修正问卷设计（放前）与佐证结论（放后）。
- 输出"技术路线图/研究框架图"。

### 第三步：研究设计与建模方案选择（核心）
- 设计框架与变量体系；确定潜变量及其量表题项。
- **大模型 Agent 依选题自动给 3~5 套建模方案**，各说明：适合的研究问题、数据形态、求解软件、检验方法与合格判据、风险与区分度。
- 队伍选定主模型（可辅差异化补充模型）。
- 问卷设计：量表题为主、为每潜变量配 3~5 题干；控制多选题；确定抽样方法与目标样本量。

### 第四步：问卷收集（人工执行，Agent 协助）
- 问卷收集须真人执行（发放/回收/访谈），Agent 不替代采集。
- Agent 协助设计发放渠道与催收策略，监控有效样本量（SEM 建议样本≥200 且需满足模型要求）。
- 数据整理：清洗、编码、缺失值处理、剔除无效问卷；记录回流率支持"调查实施"评分。

### 第五步：信度效度检验与问卷质量判定（核心）
收集后 Agent 先做质量判定，给出合格/临界/不合格**明确结论**：
1. **信度**：Cronbach α≥0.8 良好、0.7~0.8 可接受、<0.6 不合格（国赛多报告 α，合格≥0.7）。
2. **效度**：KMO≥0.8 很适合、0.6~0.7 可接受、<0.6 不宜因子分析；Bartlett p<0.05（最好<0.01）。因子载荷>0.5（严格>0.7），累计方差贡献率≥50%（建议≥60%）。
3. **模型质量**（若用 SEM/PLS-PM）：CFI≥0.90（好≥0.95）、TLI≥0.90、RMSEA≤0.08（好≤0.06）、SRMR≤0.08、χ²/df≤3。
4. **不合格修正**：删减非量表题、增补题项、重测、扩大样本；合格后方进入统计分析。

### 第六步：数据分析与建模（成员一、二协同）
- 描述性分析（配高级图）+ 差异/相关检验（卡方、T、Kruskal-Wallis、方差分析）→ 按第五步选定模型实证（每类样本数据单独成章）。
- **用户画像独立成章**：聚类/细分结果做成"人群类型 + 行为特征 + 营销对策"。
- 每个模型给出结果表（含系数、显著性、拟合指标）+ 可读解释；模型结论务必落到"下一步动作"（RFM=主力客户、KANO=功能优先级、LDA=宣传关键词等）。
- B端/产业类：加入经营数据、SWOT/PEST/DEA，按"用户角色 × 功能模块"或"企业水平 × 效率"组织。

### 第七步：结论与建议
- 结论逐条对应研究问题；建议分主体、具体、可执行、对应结论；讨论局限。

### 第八步：报告集成与格式（成员三、四协同）
- 统一全文格式：封面、摘要页、目录、表格与插图清单、正文、结论建议、参考书目、附录。
- 图表规范：统计表用三线表或主题彩色表；正文图表控量、附录放完整证据；配研究框架图、路径图、词云、雷达图、IPA 象限图、对应分析关联图、词共现/语义网络图。
- 摘要用"问题提出-调查对象/样本-方法-核心结论-建议方向"六段式；关键词包含方法词（如 RFM、KANO、LDA、SEM）以显技术含量。
- 逐字逐句润色全文。

### 第九步：终审与提交
- 核对字数（正文多限 2 万字内）/页数（总决赛上限约 50~65 页，超则拒绝）。
- **匿名检查**：不得出现校名/队名/指导教师。
- **查重**：超阈值（如 20%）取消资格。
- **地图规范**：中国地图用规范标准地图。
- 引用规范、数据可复现性（附录含脚本/原始数据/AI 使用说明）；正文与附录分开提交。

## 输出约定
