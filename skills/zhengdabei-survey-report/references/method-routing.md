# 方法路由：先问研究问题，再选方法

本文件把本地 28 篇论文、吴翌琳《大赛中的常用模型和方法解析》和一等奖作品特征分析中的方法原则整理为条件化路由。它不是“模型越多越高分”的清单。

## 四步决策

1. 定目标：本轮要描述、解释、比较/细分、预测，还是处理文本/制定策略？
2. 看数据：结构化还是非结构化？分类、连续、等级、计数、时间序列还是交易数据？数据是否真实、可追溯、足够覆盖目标人群？
3. 评资源：样本、时间、软件、团队技能、隐私和可解释性是否支持？
4. 选方法：先选最简单能回答问题的方法，再用第二证据源或稳健性分析交叉验证。

## 路由表

| 目标 | 首选候选 | 最小输入 | 必查事项 | 不能直接声称 |
|---|---|---|---|---|
| 描述现状 | 频数/比例、均值/中位数、离散程度、可视化 | 已定义总体和变量编码 | 分母、缺失值、权重、置信区间 | 样本比例等于总体比例 |
| 比较群体 | t/ANOVA、Mann-Whitney/Kruskal-Wallis、卡方/Fisher | 明确分组与结果变量 | 前提、事后检验、多重比较、效应量 | 显著差异就是因果 |
| 解释连续结果 | 线性回归、广义线性模型 | 连续/计数因变量、可解释自变量 | 残差、异方差、共线性、非线性、稳健标准误 | 相关关系就是因果 |
| 解释分类结果 | 二元/多项/有序 Logit | 分类因变量、合理编码 | 类别平衡、完全分离、VIF、拟合与校准、OR解释 | 预测准确率就是机制证明 |
| 降维/测量 | EFA/PCA、CFA/SEM、PLS-PM | 理论或探索性量表、足够样本 | 量表来源、反向题、载荷、交叉载荷、CR/AVE、拟合与样本敏感性 | α高就代表效度高 |
| 人群细分 | K-means/层次聚类、MCA | 多维行为/态度指标 | 标准化、异常值、k选择、轮廓系数、稳定性、画像外部验证 | 聚类标签天然真实 |
| 重要性与改进 | IPA | 同一属性的重要性和表现评分 | 量尺一致、象限切点、分群差异、竞品对照 | 均值象限就是唯一优先级 |
| 文本洞察 | 内容分析、词频/TF-IDF、情感、LDA、共现网络 | 有来源、时间和清洗记录的文本 | 采样偏差、分词/停用词、主题数、一致性、反讽与短文本限制 | 词云本身是结论 |
| 产品功能优先级 | KANO、联合分析 | 成对正反功能题或属性组合任务 | 题目认知负担、样本分层、编码和外部可行性 | 受访者偏好等于市场需求 |
| 路径/转化 | 漏斗、关联规则、序列分析 | 同一用户或可链接的阶段数据 | 观察窗口、回流/跳步、支持度/置信度/提升度 | 漏斗流失原因已被证明 |
| 战略建议 | SWOT/PEST/IFE/EFE、情景/敏感性分析 | 调查证据、外部资料和约束条件 | 内外部因素区分、权重来源、行动主体、预算和指标 | SWOT 四格自动产生策略 |
| 效率/产业 | DEA、投入产出、面板/时间序列 | 可比决策单元、投入产出或时间数据 | 同质性、规模报酬、变量方向、敏感性 | 效率分数等于经营因果 |

## 失败条件与降级

- 没有真实文本，不做文本挖掘；没有可链接的阶段数据，不做漏斗或关联路径。
- 量表题少于理论需要或样本不足时，不强行 SEM；改为描述、差异、相关或探索性因子分析，并标注限制。
- 聚类无稳定性或轮廓系数很低时，不把簇写成正式用户画像；改为规则分组或报告探索性结果。
- 机器学习必须保留训练/测试划分、交叉验证、基线模型和可解释性；没有足够样本就不用黑箱模型。
- 多方法只在每个方法回答不同问题时保留；“同一结论重复跑模型”不等于稳健性。

## 推荐结果表达

每个方法输出：`研究问题 → 输入与假设 → 方法 → 诊断 → 结果 → 限制 → 可执行动作`。任何系数、显著性、主题比例和预测性能都必须能追溯到真实数据、代码和版本。
