# 质量闸门与提交审计

状态只有三种：

- `pass`：证据充分，满足当前目标，可以进入下一阶段；
- `conditional`：可以探索性使用，但必须写明限制、敏感性或降级方案；
- `blocked`：关键证据或规则缺失，不能生成正式结论。

## 研究与调查

## 七维评分自查

逐项填写证据位置和状态，不把“已提到”当作“已证明”：

1. **研究选题**：真实问题、对象聚焦、范围可执行、题目准确；
2. **文献研究**：近年与主题相关，区分综述/评述，并实际影响问题和方案；
3. **方案设计**：背景、目标、方法、流程、抽样、样本量、分工和预期成果逻辑闭环；
4. **调查实施**：组织、培训、时间、渠道、记录、数据录入和前中后质量控制可追溯；
5. **分析与结论**：方法适配数据，关键维度有证据，结论对应表图并说明限制；
6. **报告文本**：章节过渡、标题层级、图表编号、图表类型、语言和商业可读性一致；
7. **研究创新**：方案、数据、方法或结论的创新解决了真实问题，不是新模型堆砌。

| 闸门 | 通过证据 | 常见阻塞 |
|---|---|---|
| 研究问题 | 一个问题对应一个可观察结果和目标主体 | 题目过大、问题只写“了解现状” |
| 文献 | 有来源、年份、与变量/方法的实际作用，区分综述与评述 | 只罗列摘要、引用无法核验 |
| 抽样 | 总体、抽样框、渠道、配额/概率规则、样本量依据 | 只写“随机发放”、样本全来自便利渠道 |
| 预调查 | 预测试记录、理解问题、时长、跳转和不通过预案 | 预调查只是“发了几十份” |
| 问卷 | 筛选逻辑、选项互斥穷尽、量表来源、反向题和伦理说明 | 诱导性题目、重复/矛盾题、无筛选条件 |
| 实施 | 时间、地点/渠道、调查员培训、统一口径、回访/抽查记录 | 集中单日发放、无现场记录 |
| 清洗 | 去重、时长、逻辑一致性、缺失/异常规则、剔除数量和理由 | 为达到显著性事后删样本 |

## 测量与模型

- 信度、效度和模型拟合阈值只是参考，不机械删题。报告题项来源、样本、估计方法和理论理由。
- 量表质量至少说明内部一致性；需要因子结构时再报告 KMO/Bartlett/EFA/CFA 等，不能用单一指标代表全部效度。
- 回归/Logit 检查编码、共线性、异常值、拟合、残差/校准、效应量和稳健性；报告 OR 时解释单位和参考组。
- SEM/PLS-PM 说明理论路径、测量模型、估计方法、样本依据、拟合/预测指标和模型修改理由；不能因达到某个阈值就声称因果。
- 聚类、机器学习和文本模型报告参数选择、稳定性/验证集、误差或主题一致性，保留可解释的业务含义。

## 结论与建议

每条结论必须有：`研究问题编号 + 数据/表图 + 结果 + 限制`。

每条建议必须有：`证据 → 对象/责任主体 → 动作 → 资源/前提 → 时间 → 衡量指标`。政府、企业、平台、学校、消费者等主体只有在与研究对象相关时才拆分。

## 文本与图表

- 文本分析仅在文本真实、相关、可追溯且合规时通过；没有文本时词云闸门为 `blocked`。
- 词云必须说明语料、清洗、分词、权重和样本量，并至少配合 Top-N 表或更深入的主题/情感/共现验证。
- 每张图表必须有图号、标题、来源、时间、样本量、单位、图后解释和对应研究问题。
- 图表类型、颜色、坐标轴和可读性必须通过 `references/visualization-guide.md` 审计。

## 篇幅与交付资产

- 写作前必须有目标正文页数、版式、附录计页方式和篇幅预算；规则未核验时页数状态为 `conditional`。
- 章节实际页数明显低于预算时，状态为 `conditional`，先补充证据、方法、结果解释或限制，不能用重复文字、空泛背景或虚构结果填充。
- 最终交付必须包含正文、篇幅预算与实际分页表、图表登记表、图表数据/代码和正文质量审计；缺任一项不能判为 `pass`。
- 常规问卷型报告应核对技术路线图、研究流程图、样本结构表/图、关键描述分析、每个核心研究问题的结果表/图、模型结果表和建议矩阵；不适用的资产必须写明理由。
- 每个核心研究问题至少绑定一张可追溯表或图。图表缺来源、样本量/分母、单位、图后解释或正文引用时，状态为 `conditional`；数值无法追溯时为 `blocked`。

## 提交前审计

- 核对当年度官方/赛区通知：组别、截止时间、页数、字体、文件格式、正文/附录、报告/PPT比例和命名。
- 全文匿名：学校、指导教师、队名、队员信息按当年要求处理。
- 中国地图使用官方规范完整版本；不确定时删除地图或先核验。
- 查重与引用：所有引文、数据来源、图片和外部指标可追溯；不得伪造引用。
- AI 使用：附公开透明说明，记录用途、人工核验和核心调查/分析的独立完成情况。
- 附录：问卷、访谈提纲、抽样/进度/调查记录、变量字典、清洗规则、脚本、输出表、原始或脱敏数据按通知提交。
