# 长篇报告生产与图表交付

这份指南解决两个交付问题：报告正文篇幅不足，以及正文没有可核验的图表和表格。篇幅目标必须来自当年度官方要求或用户明确的目标；图表必须来自真实数据、真实调查过程或可追溯文献。不得通过重复改写、虚构数据或无意义装饰填页。

## 1. 启动时锁定交付参数

在进入 `synthesis` 或写作阶段前，先填写：

```text
目标正文页数：待填 / 以官方通知为准
目标正文中文字符数：待填 / 不单独作为通过依据
页面与字体：待填
正文是否含图表：是 / 否 / 按官方模板
附录是否单独计页：待核验
图表输出能力：可直接生成 / 只能生成规格与数据模板
```

页数未知时，状态为 `conditional`，先要求确认规则或目标；不能自行把往届“2 万字”“65 页”等经验当成本届硬指标。最终以实际 Word/PDF 版式分页检查为准，字数只作为预算信号。

## 2. 篇幅预算

按目标正文页数 `P` 建立预算表。下面是起始比例，不是官方页数规则；可以根据研究问题调整，但调整后要记录理由。

| 部分 | 建议占正文 | 至少应交付 |
|---|---:|---|
| 摘要、关键词、研究框架 | 5%–8% | 问题、对象、方法、核心发现和建议；技术路线图 |
| 绪论与文献/理论 | 10%–15% | 现实痛点、研究缺口、概念/变量来源和研究问题 |
| 调查方案与实施 | 15%–20% | 总体、抽样、样本量、问卷/访谈、预调查和质量控制 |
| 数据处理与样本描述 | 10%–15% | 清洗规则、样本结构表/图、信效度或测量说明 |
| 模型与专题分析 | 25%–35% | 每个研究问题的结果表/图、诊断、解释和限制 |
| 结论、建议、不足与展望 | 12%–18% | 分主体建议、证据链、指标和限制 |

每个章节完成后记录“预算页数、实际页数、缺口原因、补充证据”。实际页数明显低于预算时，进入 `conditional`，必须先补充缺失的研究内容或重新确认目标，不能直接宣布完成。

## 3. 图表交付契约

报告输出必须同时包含正文和图表登记表。每张图表至少有以下字段：

| ID | 类型 | 标题 | 回答的研究问题 | 数据/来源 | 样本量与分母 | 单位 | 正文插入位置 | 状态 |
|---|---|---|---|---|---|---|---|---|
| T01/F01 | 表/图 | 待填 | Q1 | 数据集/文献 ID | 待填 | %/人/分 | 第 X 节后 | pass/conditional/blocked |

常规问卷型报告至少检查以下基础资产：

1. 技术路线或研究框架图；
2. 抽样、问卷筛选或研究流程图；
3. 样本结构表或图；
4. 关键变量的描述统计表/图；
5. 每个核心研究问题至少一张结果图或结果表；
6. 每个正式模型至少一张结果表，并在需要时提供诊断或稳健性表；
7. 结论到行动的建议矩阵或优先级图。

这些资产按研究设计启用：没有量表时不强制信效度表，没有文本时不强制词云，没有时间维度时不强制趋势图。可是，若某个研究问题没有任何表、图或可核验数据证据，该问题不能进入 `pass`。

## 4. 正文和图表的绑定写法

图表不能只放在文末。正文首次引用时使用固定句式：

```text
如表 T01 所示，……（说明主要差异/关系、分母和限制）。该结果回答 Q1，支持/不支持假设 H1。
```

每张图表都要有图号/表号、标题、来源、时间范围、样本量、单位、必要的计算口径和图后解释。正文中没有任何引用的孤立图表，状态为 `conditional`；来源或数值无法追溯时，状态为 `blocked`。

## 5. 没有数据时的输出形态

没有真实数据时仍可输出：

- 图表清单和研究问题映射；
- 空白结果表、变量编码和 CSV 字段模板；
- 可运行的绘图代码骨架；
- 明确标注“待真实数据填充”的图表占位符。

不得输出看起来像实证结果的示例数值、比例、显著性、模型系数或伪造图片。模拟图只能放在方法演示区，并在文件名、图题和正文中同时标注“模拟”。

## 6. 篇幅不足时的补救顺序

按以下顺序补充内容：

1. 补齐研究问题、变量定义、文献作用和技术路线；
2. 补齐总体、抽样、样本量、预调查、调查质量控制和清洗规则；
3. 增加样本结构、交叉分析、分组比较和效应量解释；
4. 补充模型诊断、稳健性、失败条件和降级方案；
5. 把每条结论扩展为“证据—结果—限制—行动”，并按责任主体拆分建议；
6. 最后再做语言润色和版式分页。

禁止用同义反复、空泛背景、连续堆砌模型、无来源图片或无解释图表填充篇幅。补救后仍达不到目标，报告状态保持 `conditional`，明确缺失材料和需要用户补充的字段。

## 7. 最终交付包

写作阶段的最终输出顺序固定为：

1. `报告正文`：按章节和图表编号引用；
2. `篇幅预算与实际分页表`：记录正文页数和缺口；
3. `图表登记表`：包含图表、来源、数据、插入位置和状态；
4. `表格/图表数据与代码`：可复核或明确标记待填；
5. `正文质量审计`：篇幅、图表、来源、编号、结论证据和提交规则。

只有五部分均存在且阻塞项已处理，才能把写作阶段标记为 `pass`。
