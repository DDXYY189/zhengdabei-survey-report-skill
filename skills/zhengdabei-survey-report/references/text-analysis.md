# 文本分析与词云：条件化工作流

文本分析只在选题确实产生可获取、可授权、与研究问题相关的文本时启用。没有真实文本、文本量过小、来源不可追溯或文本与研究对象不匹配时，状态为 `blocked`，不要为了“增加技术含量”制作词云。

## 适用判断

| 条件 | 决定 |
|---|---|
| 有开放题、评论、访谈、社交媒体或政策文本 | 可考虑文本分析 |
| 只有结构化单选/量表题 | 不做词云，使用统计分析 |
| 文本少于能支持稳定比较的数量 | 以人工编码或典型案例为主 |
| 短评极短、重复或广告水军明显 | 先清洗并评估，不能直接上 LDA |
| 研究问题是“用户提到什么” | 词频/TF-IDF/词云可作为入口 |
| 研究问题是“为什么、如何改进” | 需要主题、情感、共现或访谈验证 |

## 标准流程

```text
来源与授权 → 抽样与去重 → 清洗 → 分词与词典 → 停用词/词性
→ 词频/TF-IDF/n-gram → 词云入口图 → 情感/主题/共现
→ 分群比较 → 问卷或访谈验证 → 行动建议
```

## 词云的最低报告要求

每张词云都要在图注或正文说明：文本来源、时间范围、原始/有效文本数、去重和清洗规则、分词工具、自定义词典、停用词、权重口径和颜色含义。

词云只能回答“哪些词出现得多或权重较高”，不能单独证明需求强度、因果关系、情绪方向或策略优先级。正文至少配一张 Top-N 词频/TF-IDF 表，并在需要时用情感、主题、共现或问卷数据验证。

## 方法选择

- 词频：快速描述高频词，适合开放题和评论概览；
- TF-IDF：比较多个文档或群体的区分词；
- n-gram/共现：保留词语组合和关联结构；
- 情感分析：报告词典/模型、人工抽检、正负面定义和误判限制；
- LDA/主题模型：报告主题数选择依据、主题一致性、主题命名和人工复核；
- 内容分析：建立编码表、编码员规则和一致性检查，适合小样本文本；
- 语义网络：说明窗口大小、边阈值和网络解释规则。

## 文本质量与合规

- 记录采集日期、平台、查询条件和排除规则；
- 删除重复、广告、水军、无关文本，但保留剔除数量和理由；
- 中文专业词、品牌名、地名和缩写加入自定义词典；
- 短文本不直接套用长文本主题模型；
- 访谈和评论脱敏，遵守平台条款、版权和隐私要求；
- 代码、停用词表、词典、主题参数和中间表放入附录或可复现材料。

## 结果到行动

采用“词云发现 → 定量/定性验证 → 分群或情感差异 → 具体动作”的链条。词云不应单独占据模型章节，也不应作为唯一创新点。
