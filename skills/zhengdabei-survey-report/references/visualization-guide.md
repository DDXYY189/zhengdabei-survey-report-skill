# 图表与可视化审计

图表服务于研究问题和读者理解，不以“高级”或“漂亮”为目标。每张图只承担一个主要信息任务。

## 图表选择

| 问题/数据 | 首选 | 审计重点 |
|---|---|---|
| 类别比较 | 排序条形图、分组条形图 | 分母、排序、误差或置信区间 |
| 时间变化 | 折线图 | 时间粒度、断点、趋势解释 |
| 分布与异常 | 箱线图、直方图 | 中位数、离群点、样本量 |
| 变量关系 | 散点图、热力图 | 相关不等于因果、颜色刻度 |
| 群体画像 | 分组条形图、画像表、雷达图 | 指标标准化、避免只靠形容词命名 |
| 文本关注点 | Top-N 条形图、词云 | 词云只作入口，配清洗和权重说明 |
| 主题结构 | 主题比例、主题-关键词表、共现网络 | 主题数、阈值和可解释性 |
| 重要性与表现 | IPA 象限图 | 象限切点、群体差异、资源含义 |

## 每张图的必填字段

- 图号、标题、数据来源、时间范围和样本量；
- 指标/分母/单位和必要的计算公式；
- 颜色、符号、坐标轴和图例含义；
- 图后 1–3 句解释：发现什么、支持哪个研究问题、不能推出什么；
- 与正文研究问题、变量或结论的对应关系。

## 视觉质量闸门

- 颜色数量与含义稳定，避免彩虹色和低对比度；
- 坐标轴不截断造成误导，百分比总和和单位一致；
- 图表类型与变量类型匹配，不用饼图承载过多类别；
- 文字、图例和标注在正文尺寸下可读；
- 图表不重复叙述同一信息，附录承载完整表格；
- 数据、代码和图表版本可以互相追溯；
- 使用地图时先核验当年度规范地图，无法核验就不使用。

## 可视化自评

```text
这张图回答哪个研究问题？
读者 3 秒内能看出什么？
主要发现是什么？
分母、时间、单位和样本量是否清楚？
是否存在误导性坐标、颜色或排序？
正文是否解释了图，而不是只贴图？
```
